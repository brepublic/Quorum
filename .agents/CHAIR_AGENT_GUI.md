# Linux Chair Agent GUI：已确认需求与实施方案

确认日期：2026-09-05。用户已授权记录本文件并实施。本文记录产品决策，不授权扩展到同步核心重写、生产部署或数据迁移。

## 范围与技术

- 第一版供开发者本人在当前 CachyOS / GNOME / Wayland 环境使用。
- Rust + Slint（非 WebView）实现窗口，统一应用内部样式；系统标题栏、文件选择器可保留系统外观。
- 保留 TypeScript / Node Agent 的同步、校验、配对与恢复逻辑；发布包仍包含 Node。
- GUI 管理一个委员会、一个 Agent 实例。一个 Agent 配置绑定一个委员会。
- 支持配对、导入已有私有配置、启动、停止、重启。取消暂停。
- 关闭窗口必须停止 Agent 后退出；处理异常退出与重复进程。无托盘、自启动、多配置、自动升级。
- GUI 不内置账号登录。生成配对码、转移/撤销设备、裁决冲突继续打开 Quorum 网页。

## 配置

- 服务器地址、存储目录、CA 证书文件、定期完整扫描间隔；停止后保存生效。
- 文件变化仍可立即触发同步，扫描间隔不是网络状态刷新间隔。
- 服务器地址修改仅用于同一服务变更访问地址；其他服务必须重新配对。必须在发送旧凭据前验证目标身份或拒绝无法证明的变更。
- 存储目录仅配对时选择，或停止后选择已经完整搬迁的原目录；校验同一设备元数据，不自动搬迁。
- 导入复用原配置、身份、数据和恢复记录，不重新配对，不覆盖秘密。
- 配置仍为私有文件；不提供设备凭据、私钥、设备编号编辑。CA 只作用于子进程，禁止关闭 TLS 校验。

## 状态与文件列表

运行状态：未启动、启动中、运行中、连接异常、停止中、已退出；显示最近成功连接、当前任务。

文件按本地状态与服务器缓存分列，显示文件名、大小、进度；当前版本必须匹配。

本地状态：待上传、上传中、待下载、下载中、校验中、已就绪 - 未提交审核、已就绪 - 待审核、已就绪 - 公开可见、待删除、已删除、等待重试、失败、存在冲突。上传指主席电脑到服务器，下载指服务器到主席电脑。下载进度为实际接收字节/总大小；100% 后校验与落盘成功才就绪。已删除记录可筛选。代表浏览器尚未传完的上传不在第一版范围。

缓存状态：服务器缓存可用、服务器无缓存（本地可用需本地对应版本验证）、等待回传、正在回传、回传失败、状态未知。使用“无缓存”而不是“过期”。不可推断访问者一定是代表。服务器不可达时标记未知并保留更新时间。

已批准小范围新增 Agent 只读状态接口：沿用设备凭据及当前主机校验，只读本委员会，返回文件/版本、审核发布状态、缓存状态、更新时间；不返回内部缓存路径，不新增表，不用下载探测，不改变缓存业务。轮询刷新，传输后刷新；无需额外 SSE 协议。

## 已核实的删除行为（保持现状）

- 网页附件有“永久删除”；有权限用户确认后服务端逻辑删除并安排物理清理。
- 主席本地删除已跟踪文件会被识别为 DELETE；版本/清单匹配时自动同步为服务端已删除，无需第二次网页确认。
- 并发变化可产生冲突，断网是待同步，不能冒充已删除；未跟踪文件消失可能不影响服务端。
- 不增加 GUI 删除按钮，不改变现有删除语义。

## 实现与验收

通过子进程标准输入/输出逐行 JSON 传递命令、快照和进度，日志独立；不新增本地 HTTP 服务。进度更新节流，列表只接收安全的展示字段。

单窗口：顶部运行控制，中部可筛选文件列表，设置/配对页，可折叠日志（筛选、复制、脱敏导出），打开目录/委员会网页。

先构建并验证 Slint 中文输入、缩放、选择器与滚动；再验证控制、配置、真实传输进度与只读接口。单元测试不能替代真实 PostgreSQL、Wayland GUI、真实 TLS/Agent 验收。保留并报告用户已有未提交改动，不重启或重配现有 Agent、不部署生产。

## 当前交付记录

- 代码：`packages/storage-agent-desktop/`（Rust/Slint 窗口）、`packages/storage-agent/src/desktop-*.ts`（控制与状态）、现有 runtime 的可选进度观察接口。
- 启动：`pnpm start:storage-agent:desktop`；组装：`pnpm release:storage-agent:desktop -- --offline`（Node 缓存已存在时）。产物为 `release/storage-agent-desktop/`，不安装系统服务。
- 新只读接口：`GET /api/v1/storage-agent/file-status`，按 UUID 分页，每页 200 项；附审核与缓存状态，删除记录保留名称；未改变缓存业务或数据库结构。
- 状态约 3 秒刷新、查询超时 10 秒；进度约 100ms 节流。停止宽限期 15 秒，超时结束子进程；新 Linux CLI 和 GUI 共用 `flock`，旧版不参加此锁，使用 GUI 前须先退出旧版终端进程。
- 地址更换采用保守限制：不发送凭据，先比较两个 HTTPS 地址的已验证 TLS 证书；不同证书或旧地址不可达时拒绝。相同证书不证明数据库相同，仍遵守仅同服务更换地址的约束。
