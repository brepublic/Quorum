## 投票提交时机

原实现会在题目或选项输入框失焦时调用“创建新轮次”接口。服务器返回新 ID 后，页面重新同步新轮次的选项；这会覆盖刚添加的空选项。点击创建还可能同时触发失焦提交，两个请求竞争旧轮次。

现在题目、选项、选择方式等准备内容先保留在当前表单中，点击“创建在线表决”或“创建人工计票表决”时一次提交。**创建前离开或刷新页面，不会保存当前未提交的编辑内容。** 现有轮次、历史记录、投票资格、计票和服务端审计机制没有改动。

新增回归测试覆盖两种创建方式：输入题目并失焦、增加并填写两个选项、连续点击创建、延迟请求返回后进入投票页面。验证没有失焦创建请求、只创建一个新轮次、START 使用新轮次 ID 与 revision。
