# 实时同步恢复验收

## 第一阶段：委员会工作区（2026-10-20）

### 行为与自动回归

- 连接最近 45 秒收到服务器信号时，恢复焦点只后台刷新，不主动断开、不暂停编辑。
- 同次可见与焦点通知合并；普通刷新共用在途请求，业务变更、命令和重新连接要求后续读取。
- 读取失败、连接中断或心跳超时仍暂停提交，保留草稿；连接与最新快照均恢复后才重新开放。
- 文件及冲突刷新合并并忽略过期响应；状态详情使用现有双语错误原因。
- 六个相关测试文件共 333 项通过：CommitteeWorkspaceContext、committee-event-stream、WorkspaceNavigation、FilesPanel、SelfHostedWorkspace、CommitteeWorkspaceRoutes。完整前端 TypeScript 检查通过。

### 本机浏览器验收

使用当前源码的工作区 Context、状态组件及 HTTP/SSE 客户端，在本机临时页面连接可控的 HTTP/SSE 服务。服务返回测试数据，可通过页面按钮延迟快照、返回 503、关闭事件流或暂停心跳。未连接生产数据库，未验证远程部署。

| 操作 | 实际结果 |
| --- | --- |
| 同次触发可见与焦点通知，快照延迟 3 秒 | 读取次数由 2 增至 3；连接仍为 1、关闭为 0；保持 LIVE，提交可用 |
| 快照返回 503 | RESYNCING，提交禁用，草稿保留；详情显示“服务暂不可用，请稍后重试。” |
| 恢复成功响应 | 自动回到 LIVE，草稿保留，提交可用，未重建健康连接 |
| 服务主动关闭 SSE，恢复快照延迟 | RECONNECTING 时禁止提交，随后重新连接并读取成功后开放 |
| 停止心跳超过 45 秒 | 自动建立新连接；连接次数从 2 增至 3，关闭次数从 1 增至 2 |

焦点通知通过验收页面控件触发，休眠返回、读取超时、读取期间业务变更及过期响应另由自动回归覆盖；不将这些模拟用例表述为真实操作系统休眠测试。Cloudflare 和香港服务器配置未修改。
