# 实时同步恢复验收

## 第一阶段：委员会工作区（2026-10-20）

### 行为与自动回归

- 连接最近 45 秒收到服务器信号时，恢复焦点只后台刷新，不主动断开、不暂停编辑。
- 同次可见与焦点通知合并；普通刷新共用在途请求，业务变更、命令和重新连接要求后续读取。
- 读取失败、连接中断或心跳超时仍暂停提交，保留草稿；连接与最新快照均恢复后才重新开放。
- 文件及冲突刷新合并并忽略过期响应；状态详情使用现有双语错误原因。
- 六个相关测试文件共 333 项通过：CommitteeWorkspaceContext、committee-event-stream、WorkspaceNavigation、FilesPanel、SelfHostedWorkspace、CommitteeWorkspaceRoutes。完整前端 TypeScript 检查通过。

### 本机浏览器验收

使用当前源码的工作区 Context、状态组件及 HTTP/SSE 客户端，在本机临时页面连接可控的 HTTP/SSE 服务。服务返回测试数据，可通过页面按钮延迟快照、返回 503、关闭事件流或暂停心跳。未连接生产数据库，未验证远程部署。

| 操作 | 实际结果 |
| --- | --- |
| 同次触发可见与焦点通知，快照延迟 3 秒 | 读取次数由 2 增至 3；连接仍为 1、关闭为 0；保持 LIVE，提交可用 |
| 快照返回 503 | RESYNCING，提交禁用，草稿保留；详情显示“服务暂不可用，请稍后重试。” |
| 恢复成功响应 | 自动回到 LIVE，草稿保留，提交可用，未重建健康连接 |
| 服务主动关闭 SSE，恢复快照延迟 | RECONNECTING 时禁止提交，随后重新连接并读取成功后开放 |
| 停止心跳超过 45 秒 | 自动建立新连接；连接次数从 2 增至 3，关闭次数从 1 增至 2 |

焦点通知通过验收页面控件触发，休眠返回、读取超时、读取期间业务变更及过期响应另由自动回归覆盖；不将这些模拟用例表述为真实操作系统休眠测试。Cloudflare 和香港服务器配置未修改。

## 第二阶段：代表文件入口（2026-10-20）

### 行为与自动回归

- 事件连接建立或重建后，必须等新的文件列表读取成功才显示实时；旧连接请求不能恢复实时状态。
- 列表失败保留内容并显示现有本地化错误；心跳成功不能掩盖列表失败。
- 使用现有 `portal.status` 与文件事件更新健康时间，45 秒静默后从最后收到的事件序号重连。
- 定时与焦点刷新共用在途请求；发布、上传完成或重连保留一次后续读取。请求 20 秒超时，卸载取消请求与定时器。
- 四个相关测试文件共 72 项通过：DelegateFilePortal、self-hosted-api、DelegateFileChairPanels、DelegateFileSettingsPanel。覆盖连接与读取分别失败、排队刷新中的失败、心跳与静默、休眠返回模拟、取消请求、上传限制和失败、发布横幅及文件设置；前端 TypeScript 检查通过。

### 本机浏览器验收

使用完整 DelegateFilePortal、实际 HTTP 客户端和浏览器 EventSource，连接本机可控 HTTP/SSE 服务。测试服务提供模拟的代表身份和文件记录，不经过生产鉴权或数据库。

| 操作 | 实际结果 |
| --- | --- |
| 关闭连接后重连，列表延迟 3 秒 | 先显示离线，连接恢复但列表尚未完成时显示正在同步，读取成功后显示实时 |
| 列表返回 503 | 显示正在同步与“服务暂不可用，请稍后重试。”；保留现有文件及下载入口 |
| 列表延迟超过 20 秒 | 显示“请求超时，请稍后重试。”；不再显示实时，已有文件仍可见 |
| 恢复列表并发送发布事件 | 恢复实时，新增文件与发布横幅正常出现 |
| 在收到事件 9 后停止心跳超过 45 秒 | 连接计数从 4 增至 5，关闭计数从 3 增至 4；重连查询从 `after=8` 更新为 `after=9`，列表读取成功后恢复实时 |
| 恢复心跳并触发切回通知 | 只增加列表读取，连接计数保持 5 |

浏览器验收覆盖前端与真实网络传输；本次不涉及后端业务修改，未重跑数据库集成或生产部署验收。请求延迟、失败及焦点通知由验收控件触发，不能据此认定 Cloudflare 导致了原先的连接问题。
