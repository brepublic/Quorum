### 暂停期间的规则（用户已确认）

同一测试委员会处于暂停状态时，配对及状态查询成功，但本地文件上传反复返回 `RESOURCE_CONFLICT`。已定位：`server/src/modules/storage-agent/local-change-service.ts` 在应用本地新增、修改、重命名和删除前调用 `requireProceedingsActive`。

用户随后明确确认“暂停接收文件变更，委员会恢复才同步变更”。保留现有服务端规则，提示改为“委员会已暂停，本地文件变更将在恢复后同步。”，同步修订交接方案的中英文提示。真实 PostgreSQL 回归覆盖暂停时拒绝 UPSERT／RENAME／DELETE、不记录已接受变更，以及恢复后使用相同请求成功上传。27 项 PostgreSQL 回归全部通过。

实际 HTTPS 逐项完成新增、修改、重命名和删除：每项均在暂停时收到拒绝，服务器文件记录保持不变；恢复委员会后保持同一个运行中的 Agent，自动完成对应变更，无需重启 Agent。脱敏结果见证据目录 `pause-resume-result.json`。

## 文件清单过期冲突的定位与修复（2026-10-05）

在修改代码前，直接以原有编译后 Agent、真实本机 HTTPS 服务和 PostgreSQL 跟踪三个同时新增文件的同步。仅在临时诊断程序中记录方法名、测试文件名及序号，不记录认证信息；Agent 源码未增加调试日志。

确认的请求顺序：

| 步骤 | Agent 使用的序号 | 服务端最新序号 | 结果 |
| --- | --- | --- | --- |
| 第二轮开始读取清单 | 13 | 13 | 成功 |
| 完成第一份文件上传 | — | 13 → 14 | 成功 |
| 重放第一份文件原请求以恢复本地记录 | 13 | 14 | 原请求已完成，幂等重放成功 |
| 提交第二份新文件 | 13 | 14 | 登记 MANIFEST_STALE 冲突 |

根因为 Agent 在同一轮完成上传后仍使用轮次开始时缓存的清单。修复只在检测到新本地变更后、实际提交前重新加载清单；不更改服务端冲突判定，不自动清除已登记冲突，不改变上传恢复所用原请求。

新增两个回归用例分别模拟本地上传、网页上传任务完成推进清单后提交下一文件；原代码两项均失败，修复后通过。整个 Agent 的 12 个测试文件、111 项测试通过。真实三文件批量复测全部同步，未新增冲突；提交第二、第三份文件前分别读取服务器新序号 16、17。

脱敏原始追踪见证据目录 `manifest-stale-before.json` 和 `manifest-stale-after.json`。此前登记的冲突保留原有裁决流程，本次不自动处理。读取清单之后另有并发修改导致版本过期，仍受现有服务端规则保护。

修复后的实际批量暂停／恢复验收同时积累新增、修改、重命名、删除：暂停期间服务端记录不变，恢复后四项均完成，新文件为 `READY_REVIEW`，无须重启 Agent。结果见证据目录 `batch-pause-resume-after-fix.json`。

本轮针对用户的新截图审查并修改 Linux 原生界面。保留已有原生账号/API、配对、存储编号、暂停规则、桌面注册与同步核心；没有新增依赖、服务、存储迁移或网页流程。

### 发现与改进

| 原问题 | 当前处理 |
| --- | --- |
| 登录、CA 证书、导入、语言和手动方式都是同等级的大按钮 | 登录保留网站／邮箱／密码；证书折叠到网址旁的连接设置，证书错误时展开；语言和更多方式使用低强调入口 |
| 两个文件导入入口实际执行同一操作 | 合并为“打开配对或连接文件…”，同一选择器继续支持短期配对文件与已有私有连接 |
| 手动配对复用通用设置页，提交按钮远离字段 | 独立“使用配对码”页面，说明取得配对码的具体位置；网址、配对码、文件夹、确认按钮按任务顺序排列 |
| 路径像需要手填的输入框，配置按钮缺乏层级 | 路径为可选择的只读文字，旁边提供系统选择器；高级设置折叠，保存／取消在表单末尾，解除连接另行分隔 |
| 同步、设置、日志仍混杂运行提示与控件 | 同步显示文件与启停；设置先查看再停止编辑；日志独立；暂停提醒只出现在候选、连接确认及同步任务中 |
| 菜单使用普通下拉选择器，确认弹窗文字透底 | 独立弹出菜单与语言对话框；确认对话框改为不透明背景 |
| 小窗口提交／打开目录被挤出可视区域 | 减少表单间距，限制文件列表高度；长表单完整滚动，普通手动配对在 760×600 内可看到提交按钮 |
| 返回路径和键盘行为不一致 | 手动设置／配对码修改后返回、关闭要确认；退出连接阶段清理编辑状态；补齐控件名称和键盘激活，登录回车与按钮使用相同必填限制 |
