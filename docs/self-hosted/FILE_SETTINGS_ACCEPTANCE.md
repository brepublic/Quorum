# 文件设置验收（2026-09-06）

## 实现范围

- 主席资料页“文件设置”：委员会独立的驳回类型、代表端提示消息和三种文件类型的许可后缀。
- 管理员后台“驳回类型管理”：仅作为新建委员会的默认值，创建事务复制，已有委员会不追溯。
- 默认驳回项为内容格式不合要求、重复提交、其他。固定消息由服务器按选项解析；其他必须填写消息。历史记录保存最终消息文本。
- 默认后缀：docx、doc、pdf、odt、rtf、txt、md、xlsx、xls、ods、csv、pptx、ppt、odp。
- 代表端选择器使用 accept；浏览器提交前校验，服务器在创建上传记录前再次校验最后一个后缀，不依赖 MIME。该设置不是文件内容检测。
- 代表国家名左侧使用现有国旗组件，尺寸随文本缩放。
