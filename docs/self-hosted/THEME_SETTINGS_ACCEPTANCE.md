# 主题功能开关验收

## 重复运行相关测试

在仓库根目录执行：

```sh
source scripts/wsl-env.sh
pnpm test:self-host:themes
```

该命令自动启动 `deploy/compose.test.yaml` 中的独立 PostgreSQL 16 测试服务，默认连接 `127.0.0.1:55432`，通过 `TEST_DATABASE_ADMIN_URL` 为每项数据库测试创建并清理临时数据库。可用该环境变量覆盖地址，但只能指向允许创建临时数据库的测试服务。

覆盖主题开关、主题管理窗口、账户菜单、系统设置、语言、客户端请求、管理员权限、CSRF、版本冲突、数据库迁移和设置持久化。未使用开发实例数据库运行自动测试。

## 2026-09-18 实际结果

- 上述命令：9 个测试文件、90 项测试全部通过，无跳过。
- 首次真实数据库执行发现新增审计断言查错表；已改为身份模块实际使用的 `identity_audit_log` 并重跑通过。
- `quorum-dev` 的 `app`、`caddy` 完成镜像重建与容器更新；构建执行 `pnpm build:self-host`。
- 数据库迁移 55 完成；HTTPS `/health/ready` 返回数据库和存储正常。
- 部署后初始主题设置为 `{enabled: false, revision: 1}`。通过实际管理员 HTTP 接口启用再关闭，最终为 `{enabled: false, revision: 3}`；CSRF 错误返回 403，陈旧版本返回 409。
- 接口验收使用五分钟临时管理员会话，验收后删除；未更改用户密码或清空业务数据。
- 用 Caddy 的本地根证书验证 HTTPS，请求实际静态文件，确认部署包包含“启用主题功能（实验性）”和新接口。
- 浏览器通过已有 Vite 开发前端连接已部署后端：启用后可打开主题管理窗口；关闭并刷新后，画笔按钮、主题窗口和账户菜单主题项消失。
- 内置浏览器未信任 Caddy 本地证书，因此未直接在 HTTPS 页面进行浏览器验收；HTTPS 服务、健康接口和部署包通过显式信任该根证书的请求验证，未禁用证书校验。

本记录为主题相关验收，不表示全仓所有数据库测试已通过。
