记录日期：2026-10-06。状态：未来规划，尚未实施；实施前另行确认。

### 当前处理

系统窗口标题固定为 `Quorum Chair Agent`，页面内标题继续按语言显示。当前 GNOME / Wayland 路径的标题绘制使用单个字体，缺少中文字形；先用英文避免方框字，不修改系统字体或窗口依赖。

### 目标与交互

- 将现有图标、应用名称和菜单整合为唯一顶部栏，取消重复的系统标题栏；加入最小化、最大化／还原、关闭按钮。
- 保留足够的空白拖动区域；支持拖动窗口、双击最大化／还原和边缘调整大小。菜单及窗口按钮不能触发拖动。
- 区分激活／未激活窗口，提供清晰的悬停、键盘焦点、按钮提示和无障碍名称，适配深浅主题、中英文及显示缩放。

### 实施边界与验收

- 优先利用当前 Slint / Winit 能力，不预先升级依赖；实施前核实拖动、缩放和装饰行为。当前锁定 Slint 1.17.1，不能直接照搬 1.18 新增的 `WindowMoveArea`。
- 参考 [GNOME 顶部栏设计指引](https://developer.gnome.org/hig/patterns/containers/header-bars.html)，按操作用途分组并保持拖动空间。
- 在真实 GNOME / Wayland 上验收拖动、双击、最大化后拖动还原、边缘缩放、平铺、系统快捷键、不同缩放比例及窗口控制；检查圆角、边界和阴影表现。
- 验证关闭时的未保存确认、取消与同步退出，以及 GNOME 概览／Alt-Tab 标题和图标；软件渲染截图不能代替桌面窗口行为验收。
