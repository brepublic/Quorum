# 文件界面修改与全局样式只读检查

日期：2026-09-22。

## 边界与检查方法

仅实施本轮明确列出的文件界面问题及“文件审核 / 文件总览”合并。检查了 `src/` 下生产 TSX 的按钮、状态、业务提示、表单宽度及相关 `App.css` 规则；包含身份、委员会工作区、议事、代表文件门户、模板、存储和系统设置。其他页面只读，没有修改其组件或样式。工作区原有未提交修改保留。

浏览器实际检查：文件总览的待审核 / 已发布 / 已驳回、分享初始状态、上传回执、动议页、问题页；文件页检查中英文、常规桌面宽度以及 390 / 320 窄屏。其他页面的结论为源码检查，不代表已逐页完成浏览器验收。

## 本轮已完成

- 下载与永久删除：同宽、同高、相同圆角与图标排布，删除保留红色；原有删除确认保留。
- 驳回理由：改为灰底的卡片内信息区域，保留标题和原始理由，不再采用系统错误红框。
- 文件状态：白底、绿色已发布 / 红色已驳回 / 蓝色待审核，保留图标。
- 分享初始按钮：居中面板内全宽，增加分享图标。
- 上传：保存完成后展示成功图标、文件名、等待审核状态和“查看文件”入口；清空文件选择，方便再次上传。仍在主机保存阶段的上传不误报已提交成功。
- 移除总览内多余的“文件”标题。
- 审核按钮：绿底白字批准、红底白字驳回，各占一半并连成整行，与下载按钮同宽。
- 文件名：输入框使用卡片标题区域可用宽度；小屏下状态换行，长文件名和元数据可换行。
- 页签合并：保留“文件总览”，原 `/posts/review` 重定向到 `/posts/attachments`。主席总览内待审核按提交时间升序，已审核用审核接口提供的 `reviewedAt` 降序；保留正式文件列表的数据与下载、删除权限。待审核和已发布之间加分隔线。筛选只有“待审核与已发布”和“已驳回”。
