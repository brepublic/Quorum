# 本轮交互问题修复与验收

本轮实施沿用现有 React、HTTP API、SSE、PostgreSQL 和文件 provider。没有数据库 migration，没有修改整数百分比换算规则。测试针对当前工作区，使用随机临时数据库及临时文件目录，不连接用户的生产站点。

旧版本没有投入生产；不再把“旧版遗留 ballots 记录”列为当前故障原因。冻结的代表自主议事流程及旧表决兼容页不在本次修改范围。代表文件入口属于独立文件功能，继续维护。

## 设计依据

- [WCAG 2.2 SC 3.3.1：错误识别](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html)：指出具体错误控件，并用文字说明。国旗缺图提示放在图片选择旁，关联 `aria-invalid` / `aria-describedby`，聚焦图片控件；实测同时发现并修复了提示被表单 CSS 隐藏的问题。
- [WCAG 2.2 SC 4.1.3：状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：让辅助技术感知等待、完成和错误，避免无必要地转移焦点。下载状态使用 `role=status`，错误保留在当前页面。
- [WCAG 2.2 SC 1.4.10：重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：窄屏内容应在可见宽度内重排。国家编辑区按实际可用宽度切换纵向布局，控件不得越过单元格；在 1440、1024、390、320px 验证。
- [WCAG 2.2 SC 1.4.1：颜色使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)：操作区别不能只依赖颜色。笔记比较增加内容间距、桌面双栏与手机单栏；保存使用实心按钮和保存图标，采用服务器版本使用描边按钮和下载图标。
- [GOV.UK Design System：服务出现问题](https://design-system.service.gov.uk/patterns/problem-with-the-service-pages/)：服务故障用简明语言解释，说明已输入内容的去向，不把内部错误术语交给普通用户处理。实现先自动恢复暂时故障；需要用户选择的版本冲突才展示选择，诊断细节收起。

以上是本次具体交互的依据；1 秒 / 3 秒重试、8 秒 / 15 秒请求超时及下载等待上限属于本轮确定的产品参数，并非这些标准规定的数值。资料于 2026-10-21 在线核对。

## 问题、位置及处理

下表沿用调查清单编号，包含已修复与排除项。浏览器、页面测试和数据库测试的范围在下一节区分。

| 1 | 新笔记第一次保存尚未返回，继续输入，下一次保存又新建一条 | `SelfHostedWorkspace.tsx` / `NotesPanel` | 串行保存；始终采用创建返回的 ID；结果不确定时保留原创建正文与幂等键。 |
| 2 | 另一窗口保存笔记，本窗口收到版本冲突后自动重交旧正文 | 同上 | 冲突停止自动保存，保留草稿，比较后由用户选择版本。 |
| 3 | 编辑决议或修正案时收到新快照，输入被新快照重置 | `ProceedingsPanel.tsx` | 保留输入和开始编辑时的 revision；显示最新内容及明确选择，不自动覆盖。 |
| 4 | 提交问题被服务器拒绝，理由被清空 | `SelfHostedWorkspace.tsx` / `PointsPanel` | 仅请求成功后清空；旧表决更正界面排除。 |
| 5 | 笔记输入后不到 600ms 就切换页面，最后一段丢失 | `NotesPanel`、`useSaveBeforeLeave.tsx` | 站内导航先保存；失败保留编辑页，可继续编辑或明确放弃再离开；关闭浏览器有未保存提醒。 |
| 6 | 修改危机标题或处理时间后离开，草稿未保存 | `CrisisPanel.tsx` | 600ms 后保存草稿，站内离开先保存；发布仍是独立操作。 |
| 7 | 正在填写新 S3 配置，验证另一配置后表单消失 | `StorageAdminPanel.tsx` | 验证不清空正在编辑的配置；执行期间防止重复点击。 |

| 11 | 一次修改多个国家代码，前面已保存、后面失败 | `TemplateManagers.tsx`、Stage4 batch API | 同一次数据库操作内全部保存或全部回退；核对原代码，拒绝覆盖并发修改。 |
| 12 | 禁用账号成功，列表刷新失败，账号仍显示启用 | `SelfHostedIdentity.tsx` / `AccountManager` | 成功后立即更新该行，再刷新。 |

| 14 | 国家名称已填写但未选择国旗图片，焦点却跳到名称 | `TemplateManagers.tsx`、`App.css` | 图片控件旁显示可见提示并聚焦；补充辅助技术关联。 |

| 25 | 主题设置读取失败，页面没有恢复途径 | `ThemeSettingsPanel.tsx`、identity request policy | 先有限自动恢复；失败停止等待，保留恢复入口。 |

| 30 | 缓存文件超过 25 条，后续文件不可见 | `OperationsPanel.tsx` | 两类缓存清单各自分页，页码超出范围自动校正。 |
| 31 | 删除最后一页文件后显示空白的第 2/1 页 | `ServerVolumeAdminPanel.tsx` | 按新总数校正页码并重新读取。 |
| 32 | 清理显示失败数量，管理员不知道失败文件和原因 | volume inventory service、`ServerVolumeAdminPanel.tsx` | 返回并展示最多 50 项失败路径、错误码及尝试次数。 |
| 33 | 点击缓存额度标签不能定位对应输入 | `StorageCacheSettingsPanel.tsx` | 标签使用 `htmlFor` 关联输入。 |

此外，复查修复了三处直接影响“页面所说的状态是否真实”的实现：

1. Chair 文件已经在缓存中时，准备下载不再先检查能否新增缓存；未知异常不归为“缓存容量不足”。可确认的缓存额度及磁盘预留原因保留具体诊断。
2. 准备下载失败不再一律解释成“主席电脑离线”；只有读取到离线主机状态才使用该原因。
3. 运行状态的暂存用量采用实际接收字节，避免把声明的文件大小当成已经使用的磁盘。

本轮早先已完成的缓存提示、管理员配置权与整数联动见同日更新日志。服务器卷是否启用和服务器缓存能否写入是独立判断，不能把二者的先后发生写成因果关系。

## 超时、重试与保存边界

- 普通 JSON 读取：每次 8 秒，暂时网络或网关错误最多 3 次，重试间隔 1 秒、3 秒。写入每次 15 秒，只有既有幂等保护的操作自动重试同一请求；401、403、校验失败和版本冲突不自动重发。
- 原本持续刷新的卷清单和代表文件清单，在连续 3 轮读取失败后停止周期恢复；每轮读取自身仍受上述 3 次限制。健康状态下的正常刷新继续。后台业务 worker 的持久任务执行机制不属于浏览器请求重试。
- 下载准备最多 120 秒；上传、下载连续 30 秒无进度即结束等待。慢速但持续有进度的文件不因总时长较长而中断。取消不显示成传输错误。
- 草稿 600ms 后串行保存，站内离开先保存。浏览器刷新、关页或系统强制关闭不能保证完成最后一个异步请求；未保存时使用浏览器离开提醒。
- 本地退出立即生效；网络不可达时服务器撤销请求可能未完成。本地标记在刷新及其他标签页继续生效，后续新登录清除标记并轮换旧会话。不保存密码或 Session token 到 localStorage。
- 文件在浏览器中完整接收后保存，因此大文件会使用相应内存。这是本轮明确采用的下载方式。

## 验收

运行前加载 `scripts/wsl-env.sh`。数据库测试使用 `TEST_DATABASE_ADMIN_URL=postgresql://quorum_test:quorum_test@127.0.0.1:55432/postgres` 创建随机临时数据库。

- 前端页面与客户端测试：634 项通过；覆盖请求重试上限、上传停滞、下载完整性与取消、S3 表单保留、模板保存后列表读取失败、代表保存回执等。
- 服务端及共享测试：602 项通过，6 项 Windows 专用测试在 Linux 下明确跳过。桌面桥接测试在构建当前 Agent 后通过。
- PostgreSQL 集成：225 项通过。新增验证国家代码整批回退与并发保护、预先生成临时密码、缓存已命中时不再检查新增容量、在线主机的准备失败不误报离线。保存回执补充的 storage-agent 集成组 43 项通过。
- 浏览器交互：`pnpm test:interaction:e2e` 使用真实后端、PostgreSQL、SSE 和 Chromium，9 组情景通过，另有国家列表和笔记比较的多宽度布局检查及 11 张截图。慢响应、503 与断网通过浏览器网络拦截注入；笔记和文书的版本更新由真实服务处理。下载实际字节以 SHA-256 核对；HTTP 下载失败还通过页面下载按钮验证。
- 既有模板传输浏览器验收：5 组通过；服务器卷浏览器验收：12 组通过，包含移动布局、确认、真实文件释放及缓存保留。
- `pnpm build:self-host`、类型检查、`git diff --check` 通过。

浏览器报告和截图在 `outputs/interaction-e2e/`、`outputs/template-transfer-e2e/`、`outputs/server-volume-e2e/`，均为本地生成物，不纳入源码。脚本结束时停止服务、等待数据库连接关闭，再删除临时数据库，避免强制断开正在关闭的连接导致验收退出异常。
