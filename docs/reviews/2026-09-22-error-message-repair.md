# 错误提示修复与验收记录（2026-09-22）

## 问题与修复

快速点击决议表决按钮时，前一次请求尚未完成，后一次请求仍可能对同一席位提交相同选择。服务器正确拒绝重复记录，但浏览器将业务冲突统一显示为“当前状态不允许此操作”。原先本地撤销记录也可能在请求失败时提前变动。

决议表决现在使用同步的提交锁，覆盖投票、撤销及快照刷新；提交期间禁用投票和席位切换。服务器成功确认后才推进席位和更新撤销记录。失败保留原位置及撤销记录。服务器继续保持原有事务、权限、冲突状态和审计行为，重复投票返回 `VOTE_ALREADY_RECORDED`，无票可撤销返回 `NO_VOTE_TO_UNDO`。

此前授权的决议文件选择界面调整一起交付：下拉菜单不再被父容器裁切，标题改为“选择文件”，“使用此文件”按钮全宽并加勾选图标，“文件”排在“文本”之前且默认选中。

## 全局检查与提示设计

本次检查服务端、浏览器普通请求与代表入口、上传和下载、存储后台失败、主题导入、Node Agent 和原生桌面翻译。静态盘点包含 834 个对象形式的 `AppError` 调用；这是检查入口数量，不是缺陷数量。

沿用现有 `code + reason + params + fieldErrors` 结构，不新增服务、依赖、数据库迁移或错误协议。HTTP 状态和原有业务限制保持不变。

| 范围 | 现在提供的原因示例 |
| --- | --- |
| 席位、点名、出席 | 席位不具备资格、点名已结束、未完成出席设置、必需投票不能弃权 |
| 发言、计时、磋商 | 重复加入、当前没有发言人、计时状态冲突、磋商已结束 |
| 动议、正式表决、意向性投票、决议 | 重复投票、无票可撤销、表决未开放或已结束、规则不允许、尚有必需票未收齐 |
| 规则、模板与输入 | 具体类型或范围、重复标识、缺失翻译、文本长度上限；已有字段路径保留具体原因 |
| 账号、委员会与权限 | 具体所需角色、委员会只读或暂停、账号状态、删除与归档前置条件 |
| 文件提交、审核与发布 | 上传状态变化、类型不符、重名替换确认、文件未发布、审核状态不符 |
| 存储与主席电脑 | 磁盘空间、读写权限、S3 连接或凭据、文件校验、任务被其他连接领取、租约或版本变化 |
| 网络、上传与下载 | 网络不可达、无效服务器响应、上传中断或校验失败、主席电脑离线或源文件缺失 |
| 主题和桌面端 | 主题 3 MB 上限；桌面已知业务原因与网络原因不再统一解释为配对错误 |

共享目录位于 `packages/contracts/src/error-localization.ts`，每个原因都有中文和英文。优先说明实际失败条件，再给必要的下一步；不把提示写成文档。

- 正常请求与两种上传入口统一保留服务器结构化原因，网络错误与无效响应分别处理。
- 文件下载保留准备状态中的具体错误代码；后台存储已知失败代码也使用共享目录。上传失败的幂等重放保留安全原因。
- 插值只允许受约束的格式列表和非负安全整数上限，不插入服务器任意字符串。
- 预期的存储不可用只公开固定、安全的目录提示。未知服务器异常仍显示通用失败及请求编号，不展示路径、密钥、SQL 或原始响应。
- 未找到或无权得知资源是否存在的情况保留统一提示，避免泄露资源存在性。
- 桌面桥接只转发固定白名单原因，Rust 端使用对应的内置翻译。
- 新的契约测试扫描可恢复服务端错误分支，要求显式 reason，防止以后重新出现只有大类错误码的提示。

本记录承接 `2026-09-20-error-message-audit.md` 的只读检查；旧报告保留当时结论，不作为当前修复状态。

## Rust 补验更正

首次检查只查找了系统路径和用户目录，遗漏项目自带工具链，因此“本机没有 Rust 编译器”的判断不准确。用户指出后，按 `scripts/storage-agent-desktop.sh` 中的配置补验通过，未修改业务代码或依赖。

在仓库根目录执行以下环境配置后，运行上述 Cargo 命令：

```sh
source scripts/wsl-env.sh
export CARGO_HOME="$PWD/.tools/cargo"
export RUSTUP_HOME="$PWD/.tools/rustup"
export PATH="$CARGO_HOME/bin:$PATH"
```
