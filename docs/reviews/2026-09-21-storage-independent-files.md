# 存储位置与文件操作解耦验收

日期：2026-09-21。范围：服务器卷、主席电脑、现有 S3 实现共用菜单、提交来源、待审核、批准/驳回及代表分享规则。

## 实现

- 文件总览、文件审核、分享、上传文件、存储设置、文件设置按权限显示，与存储类型无关。未配置存储时保留入口，上传/分享提示配置存储。
- 三种存储完成持久保存后，统一创建待审核文件和来源记录；主席网页上传记录为主席，代表入口记录代表团、文件类型和提交时间。上传中或等待主席电脑保存的文件不进入可批准队列。
- 总览支持全部、已发布、待审核、已驳回及历史已上传状态；审核页只列待处理文件。批准后代表端可下载；驳回文件只在本团提交记录显示结果。
- 私有委员会访问边界、主席代办/代表操作模式、开放会期、可选席位和分享结束凭据失效规则保持不变。存储切换或故障本身不撤销分享。
- schema 64 调整分享失效和新版本审核规则。schema 65 保存服务器卷/S3 写入失败标记，原有已验证暂存数据仍可重试；页面刷新不会把已知保存失败误报为正在保存。
- 已发布历史文件不重新审核；没有来源或类型记录时显示未知值，不补造代表团或主席来源。

## 自动化检查

所有项目命令先执行 `source scripts/wsl-env.sh`。数据库测试使用独立 PostgreSQL 测试服务和自动创建的临时数据库，不使用开发业务数据库。

- 完整非数据库测试：`pnpm test:self-host --maxWorkers=2 --minWorkers=1 --testTimeout=30000 --hookTimeout=60000`，88 个文件、658 项通过。
- 完整数据库集成测试：`pnpm test:self-host:integration --maxWorkers=1 --minWorkers=1 --testTimeout=60000 --hookTimeout=60000`，9 个文件、127 项通过。
- 最终文案相关页面回归：FilesPanel、DelegateFileChairPanels、DelegateFilePortal，37 项通过；随后新增保存中/失败显示用例，代表页面 5 项复验通过。
- schema 65 后重跑存储、主席客户端及迁移集成测试：3 个文件、61 项通过；两种服务器存储的保存失败及重试单独复验：2 项通过。
- `pnpm build:self-host` 和 `pnpm verify:no-legacy-runtime` 通过。

新增服务器卷/S3 参数化用例覆盖：私有委员会的分享生命周期；主席和代表上传默认待审核；来源记录；相同提交重放不重复建文件、修改类型触发幂等冲突；未批准不可由代表下载；普通成员不能开始分享或批准；匿名访问私有文件失败；批准/驳回及本团历史；主席审核缓存额度不约束服务器卷/S3；存储暂不可用不撤销凭据；历史发布文件缺少元数据时保留状态；活动分享期间从服务器卷迁移到 S3 后下载、历史和待审核状态保持；结束分享撤销凭据。保存失败用例注入卷写入或 S3 PUT 故障，验证刷新后显示失败、审核队列为空，并以原提交重试成功。

既有集成回归覆盖：超短/超长/中断/哈希/磁盘失败无文件记录；权限撤销、暂停和审核修订冲突；真实保存完成前没有可审核文件；主席设备代际隔离、离线恢复、缓存回传；迁移失败重试及双向 S3/服务器卷迁移；事件、审计和文件状态事务回滚。

S3 证据边界：运行真实 PostgreSQL、S3 配置/提交/下载/迁移服务，网络层使用仓库已有 `IntegrationS3Transport` 测试替身；没有连接真实 S3 服务，也未声称完成真实 S3 网络端到端验收。
