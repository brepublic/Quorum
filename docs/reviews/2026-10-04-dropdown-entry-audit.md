# 下拉框入口复查与推广清单

日期：2026-10-04。

## 范围与证据

记录本次全系统下拉框盘点涉及的废弃、替代、保留条件入口，并重新检查推广清单。本轮只更新文档，不删除入口、修改规则或推广界面样式。这里的“全部废弃入口”指本次下拉框及相关页面入口范围，不是整个仓库的废弃功能清理。

逐项检查生产 TSX 的选择器、调用位置、路由、权限和状态条件；对照当前内置规则 v12 的生成逻辑。重新扫描得到 **69 处 Web 选择器声明／使用位置**，其中包含导航菜单和两个 `SpeakerSeatDropdown` 调用，不包含 `Dropdown.Item`／`Dropdown.Menu`、测试代码。重复行、国家角色和导航资源会生成多个实际控件，69 不是运行时数量。主席 Agent 的 Slint 原生语言选择器不适用 Web 样式。

本轮结论来自源码复查，没有逐页浏览器验收，也没有核对每个现有委员会使用的规则版本或数据。既有动议页高度改动的验收范围见对应 CHANGELOG。

## 重新确认的推广清单

沿用已经接受的交互：按内容自然收缩，最大高度利用可见空间并留边距；默认向下，必要时向上并避开可见导航栏；超出上限才内部滚动。短列表不强行撑高。推广只调整菜单显示，不改变搜索、选项、权限或业务流程。

### 适合高度原则，但单独处理导航结构

`WorkspaceNavigation.tsx` 的动态资源菜单包括有主持核心磋商、危机、指令、决议、表决、意向性投票，共六类。资源数量多时应利用屏幕高度并滚动，但桌面顶层菜单、更多菜单中的侧向子菜单与小屏侧栏的结构不同，需要分别验证展开方向、导航边界和子菜单。不能把动议表单的样式全局套到导航上。

账户菜单和“更多”菜单的固定操作项不是长候选列表，不优先加高；其中的动态资源子菜单按上述六类另计。

### 已实施与本次排除

- 动议类型、提出方国家已实施自适应高度，不重复计作待推广。
- 提出动议的附议国也已实施，但仅在需要附议的规则下出现；当前内置规则不需要附议。
- 正式选票代投席位／更正席位、卡片补充附议国、意向性投票代投席位、动议目标磋商从原推广清单移出，理由见入口登记。
- 语言、公开性、运作模式、席位类型（新增／单席／全部）、旗帜模式、洲别、发言名单开关、计时单位、票种／多数规则、意向性投票单双选及匿名／实名模式、文件类型、文件状态、驳回消息模式、默认操作模式、存储状态和缓存单位等固定短列表，保持内容自然高度，无须专项推广。
- 原生桌面语言下拉框由 Slint 管理，不应用 Web 下拉菜单改动。
